## 五、四条纪律

1. **别只发“你好”两个字**。首条必须带信息量，否则对方不会回第二句；
2. **数字只用简历里的**（9→3、7 节点、两次 interrupt、77 条测试、11/12、¥1），被追问要能立刻解释；
3. **主动交底课程来源**：被问“这是课程项目吗”，答“流程参考公开课程，工程实现、测试和评测是我自己做的，仓库 commit 可查”——别等对方查出来；
4. **四级没过别主动提，也别撒谎**。被问就答“在准备，日常能读英文文档”，然后把话题带回项目。
