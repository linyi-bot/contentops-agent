## 三、维护规则

1. **一张卡 = 一个可验收的产物**。写不出验收线，说明还没想清楚，别放进板子。
2. **数字只从报告来**。`reports/` 里没有的数，不进讲稿、不进简历。
3. **失败明细比总分重要**。报告只有汇总没有明细，等于没做评测。
4. **改规则要留对照**。闸门、阈值、提示词每改一次，前后两份报告都要留，A→B 才有出处。
5. **每周一次**：把完成的卡挪进「已完成」，把卡住的写进「阻塞」，再决定下一张。
