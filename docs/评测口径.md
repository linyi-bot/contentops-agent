> 状态：**待填数**。阶段 3 跑完评测集后，把真实数字写进来。

## 一、数据集

| 项 | 规格 |
|---|---|
| 规模 | 30 条（10 常规 / 10 边界 / 10 应拒答） |
| 格式 | `evals/golden/*.jsonl`，每行 `{id, topic, expect_claims[], must_cite[], should_refuse}` |
| 来源 | 自建，取自知识库覆盖的真实场景 |

## 二、指标

| 指标 | 计算方式 | 基线（mock） | 目标 |
|---|---|---|---|
| 引用命中率 | 草稿中 `[n]` 标注与实际资料条目的匹配数 / 总标注数 | 待测 | ≥ 90% |
| 事实一致性 | 核查节点判「通过」且人工复核为真的条数 / 30 | 待测 | ≥ 85% |
| 拒答准确率 | `should_refuse=true` 中被正确拒答的比例 | 待测 | ≥ 80% |
| 平均 token | 单次运行 input+output | 待测 | 逐版下降 |
| P95 延迟 | 端到端 wall time | 待测 | < 20s |

## 三、跑法（阶段 3 实现）

```bat
scripts\dev.cmd eval --dataset evals\golden --out reports\eval-YYYYMMDD.md
```

输出要求：一张表 + 每条失败样本的失败原因。只报总数不报失败明细的报告不算数。
